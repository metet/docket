# No user requirement for custom store names

The human confirmed there is no known need for a custom store name and asked what the option is for. A store name is only the repository-relative directory containing `INDEX.md`, `PARTIES.md`, `.seq/`, and the docket directories; the default is `docket/`. Record the product preference as one supported location, `docket/`, and remove `--store` unless you identify a concrete compatibility obligation that outweighs the discovery and hook complexity.
